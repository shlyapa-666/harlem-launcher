Harlem Shake Launcher (Android, Kotlin)

1. Откройте папку в Android Studio (File > Open), дождитесь Gradle Sync.
2. (Опционально) положите свой трек в app/src/main/res/raw/harlem_shake.mp3
   (имя только маленькими буквами и подчёркиванием). Без него будет таймер без звука.
3. Run на устройстве/эмуляторе. Нажмите кнопку HARLEM SHAKE:
   0–15.5 c танцует одна иконка, затем все иконки и мигающий фон, ~30 c, STOP — остановка.
4. Чтобы сделать его домашним экраном: Настройки > Приложения > Домашнее приложение.

Сборка APK без Android Studio: загрузите проект в репозиторий GitHub,
вкладка Actions > Build APK > Artifacts > HarlemLauncher-apk (app-debug.apk).
